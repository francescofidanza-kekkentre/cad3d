# CAD3D

App di modellazione 3D parametrica con tavole 2D, installabile come app (PWA).

Apri e installa: https://francescofidanza-kekkentre.github.io/cad3d/

Su tablet Android: apri l indirizzo in Chrome, menu ⋮ → «Installa app». Funziona anche offline; quando esce una nuova versione compare il pulsante «Aggiorna».
